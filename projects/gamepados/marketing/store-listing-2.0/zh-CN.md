## Full description (4000 max)

把你的手机变成PC游戏手柄。GamepadOS让你的安卓手机通过Wi-Fi或USB数据线，成为Windows电脑上的低延迟游戏手柄。无需接收器，无需额外硬件：电脑会把它识别为标准游戏手柄，支持手柄的游戏都能直接玩。

★ 使用方法
1. 在你的Windows 10或11电脑上，从 gamepad.space 安装免费的 Gamepad Server。
2. 在手机上打开GamepadOS，扫描二维码，或用USB数据线连接。
3. 开始游戏。你的手机现在就是无线或有线的PC游戏手柄。

★ 低延迟，Wi-Fi或USB
• USB模式延迟最低，只有几毫秒。
• Wi-Fi模式摆脱线缆束缚。5 GHz Wi-Fi响应最好。
• 连接稳定，提示清楚：如果电脑没有响应，点“查看原因”即可按顺序看到可能的原因。

★ 真正的手机手柄
• 摇杆、扳机、肩键、方向键和功能键，布局和主机手柄一样。
• 体感转向：倾斜手机即可在赛车游戏中转向。
• 触控板，可控制视角或像鼠标一样操作。
• 每次按键都有强劲清脆的振动反馈。
• 在90 Hz和120 Hz屏幕上依然流畅。
• 内置布局：标准布局和赛车布局。

★ 自定义布局
• 在编辑器中打造你自己的手柄布局：移动、缩放并添加按键、摇杆和触控板。
• 调整右摇杆灵敏度，让视角转得更快，或瞄准更精细。
• 注册免费账号即可备份布局，换新手机也能找回。

★ 多人同玩
最多四台手机可以连接同一台电脑。每台手机都是独立的手柄（玩家1到4），适合本地多人和同屏合作游戏。

★ 免费开始
GamepadOS可免费下载，每位玩家一开始都有免费游戏时间，无需注册账号。随时观看一段短广告即可获得更多时间，或通过Google Play一次性购买终身版，畅玩不限时。只有在你点击观看时才会出现广告。

★ 注重隐私
你的手柄操作通过你自己的网络或数据线，从手机直接传到电脑，绝不经过我们的服务器。

★ 适用于
• 安装了免费 Gamepad Server 的 Windows 10 和 Windows 11 电脑。
• 模拟器以及任何支持游戏手柄的PC游戏。
• 赛车、动作、体育、格斗和平台跳跃类游戏。
