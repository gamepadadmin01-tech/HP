## Where it goes

Play Console → **Grow users → Store presence → Main store listing**:
1. Default (English): paste the App name, Short description and Full description from `en-US.md`.
2. **Manage translations → Add your own translations** → tick the six languages → paste each file into its language.
3. Graphics: the new 2.0 screenshots and the video link (made separately; see the main notes).

## The six fixes from the report

1. **Ratings** — done in the app: 2.0.0 asks for a Google Play rating with Google's own card after a good session.
2. **Screenshots: 4 of 18 slots** — new 2.0 screenshots, 8 per device type, one benefit each, per language.
3. **Title used 7 of 30 characters** — now "Gamepad: PC Phone Controller" (PC, phone, controller are the most-searched words).
4. **Long description missed "gamepad", "low", "turn"** — all three now appear, plus "phone", "pc", "usb", "wi-fi",
   "wireless", "controller", "low latency".
5. **No preview video** — an animated ~30-second video made from the app; upload to YouTube (public or unlisted,
   no ads, no music claims) and paste the link in the listing.
6. **One language only** — six translations here, and the app itself is being translated to match.

Words that must match the app's own translations once it is translated: the "See why?" button
(zh 查看原因 · ja 原因を見る · pt Ver por quê? · es ¿Por qué? · id Kenapa? · hi कारण देखें).
