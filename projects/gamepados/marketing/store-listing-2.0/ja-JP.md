## Short description (80 max)

スマホを低遅延のPC用ゲームパッドに。Wi-FiまたはUSBで接続、レシーバー不要。

## Full description (4000 max)

スマホがPC用ゲームパッドに。GamepadOSは、AndroidスマホをWindows PC用の低遅延ゲームコントローラーにするアプリです。Wi-FiでもUSBケーブルでも使えます。レシーバーも追加の機器も不要。PCからは標準のゲームコントローラーとして認識されるので、コントローラー対応のゲームならそのまま遊べます。

★ 使い方
1. Windows 10または11のPCに、gamepad.space から無料の Gamepad Server をインストール。
2. スマホでGamepadOSを開き、QRコードを読み取るか、USBケーブルで接続。
3. あとは遊ぶだけ。スマホがワイヤレス／有線のPC用ゲームパッドになります。

★ 低遅延、Wi-FiでもUSBでも
• USBモードなら遅延はわずか数ミリ秒。
• Wi-Fiモードならケーブルなしで自由に。5 GHzのWi-Fiがおすすめです。
• つながらないときも安心：PCが応答しない場合は「原因を見る」をタップすると、考えられる原因を順番に確認できます。

★ 本格的なスマホコントローラー
• アナログスティック、トリガー、バンパー、十字キー、ボタンを家庭用ゲーム機のコントローラーと同じ配置で。
• ジャイロ操作：スマホを傾けてレースゲームでハンドル操作。
• タッチパッドで視点操作やマウスのような操作も。
• ボタンを押すたびに、しっかりとした振動フィードバック。
• 90 Hz・120 Hzの画面でもなめらか。
• 内蔵レイアウト：スタンダードとスタンダード・レーシング。

★ レイアウトを自由にカスタマイズ
• エディターで自分だけのレイアウトを作成：ボタン、スティック、タッチパッドを移動・リサイズ・追加。
• 右スティックの感度を調整して、視点をすばやく動かしたり、狙いを細かく合わせたり。
• 無料アカウントでレイアウトをバックアップ。機種変更しても元どおり。

★ みんなで遊べる
1台のPCに最大4台のスマホを接続できます。それぞれが独立したゲームパッド（プレイヤー1〜4）になるので、ローカル対戦や協力プレイに最適です。

★ 無料ではじめられる
GamepadOSは無料でダウンロードでき、最初から無料のプレイ時間があります。アカウント登録は不要です。短い広告を見ればいつでもプレイ時間を追加でき、Google Playで一度購入すればライフタイム版として無制限に遊べます。広告は自分でタップして見るときだけ表示されます。

★ プライバシーに配慮
コントローラーの操作は、自宅のネットワークまたはケーブルを通ってスマホからPCへ直接届きます。当社のサーバーを経由することはありません。

★ 対応環境
• 無料の Gamepad Server をインストールした Windows 10／Windows 11 のPC。
• エミュレーターや、ゲームコントローラー対応のあらゆるPCゲーム。
• レース、アクション、スポーツ、格闘、アクションパズルなど。
