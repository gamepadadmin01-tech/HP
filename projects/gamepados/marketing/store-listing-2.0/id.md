## Full description (4000 max)

Ubah HP kamu jadi gamepad PC. GamepadOS membuat HP Android kamu menjadi kontroler game berlatensi rendah untuk PC Windows, lewat Wi-Fi atau kabel USB. Tanpa dongle, tanpa perangkat tambahan: PC mengenalinya sebagai kontroler game standar, jadi game yang mendukung gamepad langsung bisa dimainkan.

★ CARA KERJA
1. Pasang Gamepad Server gratis di PC Windows 10 atau 11 kamu dari gamepad.space.
2. Buka GamepadOS di HP, lalu pindai kode QR, atau sambungkan dengan kabel USB.
3. Main. HP kamu sekarang jadi gamepad PC, nirkabel atau pakai kabel.

★ LATENSI RENDAH, WI-FI ATAU USB
• Mode USB untuk latensi terendah, hanya beberapa milidetik.
• Mode Wi-Fi untuk main tanpa kabel. Wi-Fi 5 GHz memberi respons terbaik.
• Koneksi stabil dan bantuan yang jelas: kalau PC tidak merespons, ketuk "Kenapa?" untuk melihat penyebab yang paling mungkin, secara berurutan.

★ KONTROLER SUNGGUHAN DI HP
• Stik analog, trigger, bumper, D-pad, dan tombol aksi, dengan tata letak seperti kontroler konsol.
• Setir giroskop: miringkan HP untuk menyetir di game balap.
• Touchpad untuk menggerakkan kamera atau dipakai seperti mouse.
• Getaran yang kuat dan tegas di setiap tekanan.
• Lancar di layar 90 dan 120 Hz.
• Tata letak bawaan: Standar dan Standar Balap.

★ TATA LETAK SESUKA HATI
• Buat tata letak kontroler sendiri di editor: pindahkan, ubah ukuran, dan tambahkan tombol, stik, dan touchpad.
• Atur sensitivitas stik kanan supaya kamera berputar lebih cepat atau bidikan lebih presisi.
• Cadangkan tata letak kamu dengan akun gratis dan pulihkan di HP baru.

★ MAIN BARENG
Sambungkan sampai empat HP ke satu PC. Setiap HP jadi gamepad sendiri, Pemain 1 sampai 4, untuk game multiplayer lokal dan co-op.

★ GRATIS UNTUK MULAI
GamepadOS gratis diunduh, dan setiap pemain langsung dapat waktu main gratis, tanpa perlu akun. Tonton iklan singkat untuk tambahan waktu kapan saja, atau beli Selamanya untuk main tanpa batas, cukup bayar sekali lewat Google Play. Iklan hanya muncul saat kamu mengetuk untuk menontonnya.

★ PRIVASI TERJAGA
Input kontroler kamu langsung dikirim dari HP ke PC lewat jaringan atau kabel milikmu sendiri. Tidak pernah melewati server kami.

★ BISA DIPAKAI UNTUK
• PC Windows 10 dan Windows 11 dengan Gamepad Server gratis.
• Steam, emulator, dan semua game PC yang mendukung kontroler.
• Game balap, aksi, olahraga, fighting, dan platformer.
