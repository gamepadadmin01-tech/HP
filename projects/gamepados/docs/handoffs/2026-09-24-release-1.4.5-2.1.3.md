## ⚠️ Windows keeps marking files Hidden
Two builds failed today because files on D: carried the Windows **Hidden** attribute — 36 app source files,
60 UI files, 18 server files, git bookkeeping files, and even **15,802 freshly generated files** in
`pc-server-rs/target`. Symptoms point nowhere near the cause:
- Gradle: `resource drawable/ic_launcher_foreground not found` (AGP skips hidden resource files; Kotlin compiles fine).
- Rust: `LNK1104` from link.exe (it cannot overwrite a hidden .pdb/.exe).
- git: "Permission denied" on COMMIT_EDITMSG / FETCH_HEAD (2026-09-23 handoff).
Fix (attribute only, content untouched):
`Get-ChildItem -Force -Recurse <dir> -File | ? { $_.Attributes -band 'Hidden' } | % { $_.Attributes = $_.Attributes -band -bnot [IO.FileAttributes]::Hidden }`
The source of the attribute is **not yet found** — something on this PC applies it to new files too.
