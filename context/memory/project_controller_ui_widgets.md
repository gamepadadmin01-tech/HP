**2026-07-19 D-pad + animation pass (user-requested, build-verified + browser-verified):**
- **D-pad is now STRICT 4-WAY.** `Dpad.dirsAt()` was overlapping 67.5° bands (deliberate 8-way diagonals + roll-through) → user hated the "adjacent buttons firing together" and could get opposite pairs. Now it snaps the single pointer to the ONE nearest cardinal (`atan2` → -45/45/135 quadrants). Result: only ever ONE arrow active; accidental adjacent AND impossible opposite (up+down / left+right) are both eliminated. It's single-pointer (pid guard), so no two-finger diagonals either — by design. To restore diagonals later, widen `dirsAt` back to overlapping bands.
- **Animations calmed to "smooth pale fades"** (user: old feel was "aggressive"). Across Btn/Dpad/RightStick/TriggerPill: press scale 0.92→0.96; removed the springy release overshoot `cubic-bezier(0.34,1.4,0.5,1)` → gentle symmetric `transform 0.16s cubic-bezier(0.22,0.61,0.36,1)`; all glows/highlights now ALWAYS rendered with `opacity 0↔~0.4-0.5` + `transition opacity 0.2s ease-out` (a transition can't animate from `transparent`/conditional-mount, so they used to pop in). D-pad sector highlight fades at pale 0.5 opacity; label fill transitions. Trigger analog FILL left instant (input latency), only its glow/stroke fade.
