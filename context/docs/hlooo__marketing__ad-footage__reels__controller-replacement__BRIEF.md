## Intent

A fast, beat-synced 20-second Instagram Reel that convinces PC gamers to replace
their Xbox-style controller with GamepadOS (free Android app that turns the phone
into a PC game controller). Viral-hook structure: open on an unanswered question,
agitate pain (price, stick drift, batteries), reveal the phone transforming into
a controller, hit max-performance stats, close with a free-vs-₹4,499 comparison
and a comment-CTA. Ends with a seamless loop back into the hook.

## Assets

- None supplied. All visuals invented (vector controller, phone mockup, stat
  cards) in brand style.

## Customizations

- Brand palette (strict): bg #131923, orange #FF6A1A, cyan #35E0FF, off-white
  #F5F2EC; subtle grid texture; orange glow vignette at frame bottom.
- Ultra-bold geometric sans, tight letter-spacing; text max 6 words/line; all
  text inside center 80% safe zone (Instagram UI overlays the edges).
- Scene timings (20s total @ beat-grid ~140 BPM):
  1. 0.0–1.5  HOOK — Xbox-style controller + ₹4,499 tag, "Want to REPLACE this?"
  2. 1.5–4.5  PAIN — 3 rapid 1s cuts: "Stick drift." / "Dead batteries." / "₹4,499?!" + red X
  3. 4.5–6.0  TURN — black cut, phone rises: "Your replacement is already in your pocket."
  4. 6.0–9.0  TRANSFORM — phone rotates landscape, controller UI ignites, orange
     shockwave, "GamepadOS." (biggest beat)
  5. 9.0–14.0 STATS — cards slam in: "2.5ms LATENCY" / "1000Hz POLLING" (cyan
     graph spike) / "GYRO STEERING" (phone tilts like a wheel)
  6. 14.0–17.0 KILL SHOT — split top/bottom: grey controller ₹4,499 vs glowing
     phone ₹0; grey one crumbles. "Same games. Zero rupees."
  7. 17.0–20.0 CTA — logo + "100% FREE. No ads." + Comment "PAD" 👇 +
     gamepad.space pill; final ~0.3s flickers scene-1 controller for seamless loop.
- No narration. No baked-in music: the user adds trending audio inside the
  Instagram editor (reach strategy); cuts are timed to a ~140 BPM grid
  (~0.43s/beat) so any phonk/trap track lands.

## Notes

- Never fade text in — every text element fully visible on its scene's first frame.
- Constant punch-in (scale 100→108%) on every scene; cuts and slams only.
- No watermark. Brand voice only ("GamepadOS", "gamepad.space"); never a personal name.
- Xbox-style controller must be a generic stylized vector — no Xbox logo/trademark.
