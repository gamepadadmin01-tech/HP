Getting started

Set up in three steps

1

Install the PC server

Download the Gamepad Server installer and run it. It installs the ViGEmBus virtual-gamepad driver (so games see a real Xbox 360 controller) and the Windows Firewall rule for you — one permission prompt during setup, then it starts silently every time with nothing left to configure.

Windows SmartScreen may warn because the app is unsigned. Choose More info → Run anyway. Some antivirus tools flag new unsigned apps — allow it or add an exclusion.

2

Install the app and pair

Install the Android APK, open it, tap Scan and point the camera at the QR code in the server window. Both devices must be on the same Wi-Fi network — pairing is instant and remembered for next time.

Prefer a cable? Enable Developer options → USB debugging on the phone, plug it in and accept the prompt. The server handles the USB connection automatically — no Wi-Fi needed.

3

Pick a layout and play

Choose a preset — racing, shooter or emulator — or build your own in the layout editor: drag, resize and place every control. Turn on gyro steering per layout if your game wants it. Rumble comes back from the game automatically.

Troubleshooting

When it doesn't connect

Almost every connection problem is one of these six. Work top to bottom.

Phone can't reach the PC

Make sure both devices are on the same Wi-Fi network. Guest and hotel networks often block device-to-device traffic (client isolation) — and phone hotspots usually block it too. A normal home router works.

Using a VPN?

VPNs (Surfshark, NordVPN and friends) reroute or block local traffic. Fully quit the VPN app on the PC — not just disconnect — then restart the server and scan the fresh QR.

Firewall blocked it

The installer adds a Windows Firewall rule that allows Gamepad Server on any network, so this is handled for you. If you used the standalone .exe instead and declined the prompt, just run the installer — or allow inbound UDP 7777–7786 for GamepadServer manually.

QR scans but nothing happens

The QR encodes your PC's network address. If the PC switched networks, restart the server to get a fresh QR. Also check Windows isn't treating your network as "Public" with device isolation turned on.

Driver didn't install

ViGEmBus needs that one-time Windows permission. Re-run the server and accept it, or install the driver manually from the official ViGEmBus releases page, then start the server again.

"Smart App Control blocked an app that may be unsafe"

This is Windows 11 refusing to run the server because we haven't bought a code-signing certificate yet — not a virus warning, and nothing is wrong with your PC. Smart App Control only trusts software from publishers who pay for a certificate, and we're a one-person project that can't justify that cost yet. It's on our list.

Most people never see this: Smart App Control is only switched on by default on fresh Windows 11 installations. If you do see it, the honest options are to wait until we're signed, or to turn Smart App Control off in Windows Security → App & browser control → Smart App Control. Be aware that turning it off is permanent — Windows can only switch it back on by resetting the PC, so please don't do it on our account unless you're comfortable with that trade.

Game doesn't see the controller

The pad shows up as an Xbox 360 controller. Verify Windows sees it: press Win+R, run joy.cpl. On Steam, enable Xbox controller support under Settings → Controller.
